# Study Room Booking

Ứng dụng đặt phòng học theo thời gian thực được phát triển bằng React Native và Expo.

## Features

- Hiển thị danh sách phòng học
- Tìm kiếm phòng theo tên
- Lọc phòng theo trạng thái và sức chứa
- Xem thông tin chi tiết phòng
- Chọn ngày và khung giờ
- Đặt phòng
- Ngăn đặt trùng khung giờ
- Quản lý lịch đã đặt
- Hủy đặt phòng
- Đồng bộ dữ liệu realtime với Firebase Firestore
- Local Notification Reminder
- Quản lý global state bằng Zustand
- Tối ưu danh sách bằng FlatList và React.memo

## Technologies

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- Firebase Firestore
- Expo Notifications
